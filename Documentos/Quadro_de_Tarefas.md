# Quadro de Tarefas

**SPG - SmartPark Guarita**

Tarefas de cada sprint, agrupadas por item do backlog. É a versão para leitura no GitHub do arquivo `Backlog_Sprint_e_Quadro.xlsx`, que é o que vai para o Moodle.

**Como usar:** para marcar uma tarefa como feita, troque `[ ]` por `[x]`. Uma tarefa em andamento pode ganhar `(fazendo)` no fim da linha. Os responsáveis entre parênteses são sugestões, a confirmar na Reunião de Planejamento do Sprint.
